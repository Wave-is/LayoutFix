# LayoutFix — состояние готовности и доказательства

Дата последней проверки: 24 августа 2026 года.

Этот документ дополняет `VISION.md`: видение определяет требования, а здесь фиксируется, какие из них уже доказаны тестами. Пока остаются незакрытые внешние release gates, продукт следует называть **early preview / beta**, а не стабильным релизом.

Актуализация 24 августа: журнал внешней машины выявил повторяемые `LF-HK-004` в Chrome/Premiere/Telegram из-за ложной смены input-generation на подавленных повторах хоткея и из-за сложных форматов буфера. Подавленные повторы теперь сохраняют ownership, а bitmap и поддерживаемые application streams клонируются по значению; реальный clipboard E2E побайтно восстановил text/image/private stream без раскрытия имени private format. Узкий Premiere rename-профиль принимает оба наблюдавшихся главных класса (`Premiere Pro` и `DroverLord - Window Class`) и заменяет точное полное или частичное выделение через bounded `EM_REPLACESEL`, не затрагивая clipboard. На 4K при system DPI 144 (150%) семь русских Settings snapshots прошли без перекрытий; `Edit`, `RichEdit`, 100/100 physical soak и три последовательные 12-case матрицы также прошли. Повтор реального Adobe gate корректно заблокирован, потому что Premiere уже был открыт пользователем; эта сессия не затрагивалась и не считается новым live Adobe pass.

## Команды локальной проверки

```powershell
dotnet restore LayoutFix.sln
dotnet test LayoutFix.sln -c Release
dotnet build tests\LayoutFix.WindowsE2E\LayoutFix.WindowsE2E.csproj -c Release
dotnet publish src\LayoutFix\LayoutFix.csproj -c Release -r win-x64 --self-contained true
dotnet list LayoutFix.sln package --vulnerable --include-transitive
tests\Run-AutoCorrectionE2E.ps1 -Runs 10 -SoakIterations 25
tests\Run-PartialInputE2E.ps1 -Runs 10
tests\Run-SelectionOwnershipE2E.ps1 -Runs 10
tests\Run-ConfigurableHotkeyE2E.ps1 -Runs 3
tests\Run-ManualCorrectionMatrixE2E.ps1 -Runs 3
tests\Run-TextCompatibilityE2E.ps1 -Runs 10 -IncludeWordPad
tests\Run-BrowserCompatibilityE2E.ps1 -Runs 2
tests\Run-AdobeNonEditableE2E.ps1 -Application Premiere -Runs 3
tests\Run-AdobeNonEditableE2E.ps1 -Application AfterEffects -Runs 3
```

Детерминированные Windows E2E запускаются отдельными режимами `LayoutFix.WindowsE2E.exe`: `--settings-snapshot`, `--compatibility-probe-test`, `--worker-isolation-test`, `--worker-startup-timeout-test`, `--secure-target-test`, `--noneditable-pipeline-test`, `--noneditable-exit-race-test`, `--translator-behavior-test`, `--translator-localization-test` и `--notification-focus-test`. Реальный clipboard проверяется через `--clipboard-formats-test`; unlocked interactive session — обычным запуском (cold-start), `--physical-soak 1000` и `--hotkey-vk-test <hotkey> <decimal-vk>`. After Effects rename проверяется режимом `--aftereffects-rename-test <main-hwnd>` после загрузки собственного `tests\fixtures\AfterEffectsEditableFixture.jsx`; режим допускает ввод только после exact `TEST`/UIA/foreground-проверок. Реальные модели дополнительно проверяются режимами `--download-model <light|pro|alma>`, `--worker-model-switch-test <path-to-LayoutFix.exe>`, `--worker-translation-test <path-to-published-LayoutFix.exe> [light|pro|alma]`, адресным `--worker-translation-case <path> <light|pro|alma> <case-id>` и расширенным `--worker-translation-matrix <path> [light|pro|alma]`; неизвестный model id отклоняется кодом 29, неизвестный case id — 38, исключённый для выбранной модели case — 39.

Физические compatibility suites должны выполняться только в unlocked Windows desktop session, где тестовое окно смогло доказанно стать foreground. E2E не отправляет замену, если foreground и точный `TEST` не подтверждены; unit-тест не заменяет этот gate. Классический suite создаёт и удаляет только собственный временный WordPad-файл и завершает только запущенный им процесс. Browser suite создаёт локальную страницу и отдельный временный профиль Edge/Chrome для каждого запуска, затем завершает только свой process tree и удаляет только каталоги с точными префиксами `LayoutFix.EdgeE2E.`/`LayoutFix.ChromeE2E.` внутри системного temp; итоговая проверка блокирует gate при любом остатке. Пользовательские документы, профили браузера и существующие процессы не являются целями тестов.
