Download **LayoutFix_Setup.exe** for a regular Windows installation.

Shift+Scroll Lock now has a copy-only fallback for the Steam web document reported by WavePC. If no writable editor can be verified, LayoutFix tries Ctrl+C once and checks that Steam supplied new clipboard content. It restores the previous clipboard and offers **Copy corrected text**. Only clicking the action puts the correction on the clipboard. Paste it manually into the desired field. No text is injected into an unverified document.

The Windows browser fixture covers the real clipboard, hotkey, correction and copy action. The Steam-specific window signature comes from field diagnostics; this is not a live Steam client certification.
